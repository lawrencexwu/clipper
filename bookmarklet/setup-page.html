Clipper bookmarklet

Drag this button to your bookmarks bar:

📎 Clipper

Click it on any article page. A new tab opens with the clipped markdown plus buttons to Copy, Save to Files (iCloud Drive on iPhone), or Open in Claude.ai.

iPhone Safari setup

Safari iOS does not let you drag bookmarklets, so you set it up manually:

  1. Bookmark any page in Safari (Share → Add Bookmark)
  2. Open Bookmarks, tap Edit, tap the new bookmark
  3. Rename it "Clipper" and replace the URL with the code below (copy with the button)
  4. Save

Mac Safari setup

Drag the button above to the Favorites bar. If the bar is hidden: View → Show Favorites Bar.

How it works

The bookmarklet runs the same extraction core as the Chrome extension and Claude Code skill — Mozilla Readability with per-site adapters for X / Substack / NYT, then Turndown for clean Markdown. Output includes a YAML frontmatter block compatible with Obsidian.
